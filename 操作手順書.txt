================================================================
  ハローワーク求人情報収集ツール - GitHub Actions版 操作手順書
================================================================

【概要】
このパッケージは GitHub Actions を使って Windows EXE を自動生成します。
.bat ファイルは一切不要です。

================================================================
  EXE のビルド手順（初回のみ）
================================================================

1. GitHub にリポジトリを作成（無料アカウントで可）
   https://github.com/new

2. このフォルダの内容をリポジトリにプッシュ
   （GithubDesktopアプリを使うと簡単です）

3. GitHub のリポジトリページを開き
   [Actions] タブ → [Windows EXE ビルド] をクリック

4. [Run workflow] → [Run workflow] を押す

5. 完了後（約3〜5分）、ワークフローをクリックして
   下部の「Artifacts」から
   「ハローワーク求人情報収集ツール_Windows」をダウンロード

6. zipを解凍すると「ハローワーク求人情報収集ツール.exe」が入っています

================================================================
  アプリの使い方
================================================================

【起動】
  「ハローワーク求人情報収集ツール.exe」をダブルクリック

【検索条件の設定】
  ・都道府県   : プルダウンから選択（指定なし = 全国）
  ・キーワード  : 職種名・スキルなど自由に入力
  ・雇用形態   : 正社員 / 契約社員 / パート等
  ・最大取得件数: 一度に取得する上限（推奨: 50〜200件）
  ・リクエスト間隔: サーバー負荷軽減のため 2秒以上推奨
  ・保存先フォルダ: Excel出力先（デフォルト: デスクトップ）

【操作手順】
  1. 条件を設定して [▶ 収集開始] をクリック
  2. 右側のログで進捗を確認
  3. 完了後 [Excelエクスポート] でExcelファイルを保存

================================================================
  注意事項
================================================================

・ハローワークのサイト構造変更により動作しない場合があります
・過度なアクセスは避け、リクエスト間隔は2秒以上を推奨します
・収集したデータは適切な目的でのみご利用ください

================================================================
  トラブルシューティング
================================================================

・起動しない場合
  → Windows Defender が誤検知することがあります
  → 「詳細情報」→「実行」で起動できます

・「Windowsによって保護されました」と表示される場合
  → 「詳細情報」→「実行」をクリック
