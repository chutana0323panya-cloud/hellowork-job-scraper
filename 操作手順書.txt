================================================================
  ハローワーク求人情報収集ツール v1.2.0 - 操作手順書 (Windows版)
================================================================

【v1.2.0 修正内容】
  ✅ TLS証明書エラー解消 (Could not find a suitable TLS CA certificate bundle)
  ✅ タイムアウトエラー解消 (Read timed out / Max retries exceeded)
  ✅ エラー発生時も収集済みデータを保持・エクスポート可能
  ✅ 途中停止→再開機能（チェックポイント保存）

================================================================
  EXE のビルド手順（初回のみ）
================================================================

1. GitHub のリポジトリページを開く
   https://github.com/chutana0323panya-cloud/hellowork-job-scraper

2. [Actions] タブ → [Build Windows App] をクリック

3. [Run workflow] → [Run workflow] を押す

4. 完了後（約3〜5分）、ワークフローをクリックして
   下部の「Artifacts」から「HelloWorkJobScraper_Win」をダウンロード

5. zipを解凍すると「ハローワーク求人情報収集ツール.exe」が入っています

================================================================
  アプリの使い方
================================================================

【起動】
  「ハローワーク求人情報収集ツール.exe」をダブルクリック

【検索条件の設定】
  ・都道府県    : プルダウンから選択（指定なし = 全国）
  ・キーワード   : 職種名・スキルなど自由に入力
  ・雇用形態    : 正社員 / 契約社員 / パート等
  ・最大取得件数  : 一度に取得する上限
  ・リクエスト間隔 : サーバー負荷軽減のため 2秒以上推奨
  ・保存先フォルダ : Excel出力先（デフォルト: デスクトップ）

【基本操作】
  1. 条件を設定して [▶ 収集開始] をクリック
  2. 右側のログで進捗を確認
  3. 完了後 [Excelエクスポート] でExcelファイルを保存

================================================================
  新機能：エラー時の救済策
================================================================

【救済策①：エラー発生時に自動でデータ保持＋再開】
  ・エラーが発生しても、それまでに収集したデータは消えません
  ・エラー停止後も [Excelエクスポート] ボタンが有効のままです
  ・収集済みデータは自動的にチェックポイントとして保存されます
  ・「中断からの再開」エリアの [▶ 前回の続きから再開] を押すと
    止まった次から収集を再開します

【救済策②：人力で途中停止→ダウンロード→再開】
  1. 収集中に [■ 停止] ボタンを押す
  2. 停止後 [Excelエクスポート] でデータを保存
  3. 「中断からの再開」の [▶ 前回の続きから再開] を押す
  4. 前回終了したページの次から自動的に続きを収集します

================================================================
  エラー対策の詳細
================================================================

【エラー1：TLS証明書エラー】
  症状：「Could not find a suitable TLS CA certificate bundle」
  対策：v1.2.0 で自動修正済み。certifi ライブラリを組み込み。

【エラー2：タイムアウト (Read timed out)】
  症状：「HTTPSConnectionPool Read timed out」
  対策：タイムアウトを90秒に延長 + 最大5回自動リトライ（指数バックオフ）
        一時的な通信障害は自動復旧します。

【エラー3：最大リトライ超過 (Max retries exceeded)】
  症状：「HTTPSConnectionPool Max retries exceeded」
  対策：接続エラー時に2→4→8→16→32秒間隔で自動再試行します。
        それでも失敗した場合はその件のみスキップして継続します。

================================================================
  注意事項
================================================================

・ハローワークのサイト構造変更により動作しない場合があります
・過度なアクセスは避け、リクエスト間隔は2秒以上を推奨します
・収集したデータは適切な目的でのみご利用ください
・チェックポイントファイルは %USERPROFILE%\.hellowork_checkpoint.json に保存

================================================================
  トラブルシューティング
================================================================

・起動しない場合
  → Windows Defender が誤検知することがあります
  → 「詳細情報」→「実行」で起動できます

・「Windowsによって保護されました」と表示される場合
  → 「詳細情報」→「実行」をクリック
